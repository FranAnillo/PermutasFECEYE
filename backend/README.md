# API Permutas FECEYE

Adaptación de TFMPermuta (ETSII) con autenticación local y Telegram comentado.
La instalación, migraciones, endpoints y límites de esta versión se documentan en
[el README del proyecto](../README.md).

```sh
npm ci
cp .env.example .env
# Completar .env y aplicar ambas migraciones antes del registro.
npm start
```

Pruebas: `npm test`. Desarrollo: `npm run dev`.
